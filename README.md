# Маленький мир — симулятор автономного поселения

Изометрический «диорамный» мир, который живёт сам по себе: жители работают,
общаются, дружат, ссорятся, строят, влюбляются, болеют, стареют и покидают
поселение. Игрок только наблюдает.

## Запуск

Проект — чистый статический веб-сайт без сборки. Нужен любой статический
сервер (ES-модули не работают с `file://`):

```bash
# вариант 1: python
python -m http.server 8123 --directory .

# вариант 2: node
npx serve -l 8123 .
```

Открыть http://localhost:8123

## Управление

| Действие | Как |
| --- | --- |
| Выбрать жителя / здание | клик |
| Панель поселения | кнопка «Поселение» или двойной клик по пустому месту |
| Камера | перетаскивание, колесо — зум |
| Пауза / скорость | `Space`, `1–4` или кнопки в топбаре |
| Следить за жителем | `F` или кнопка в карточке |
| Новый мир | `R` или кнопка ↺ |
| Справка | `H` |

## Архитектура

```
js/
  sim/     — логика симуляции (не зависит от рендера)
    defs.js       профессии, здания, товары, константы
    rng.js        детерминированный ГСЧ (mulberry32)
    names.js      пулы имён
    time.js       календарь: дни, сезоны, годы
    world.js      карта-остров, здания, деревья, A*
    villager.js   сущность жителя: потребности, черты, память
    brain.js      система решений (utility AI)
    actions.js    исполнение действий
    social.js     отношения, взаимодействия, конфликты, пары
    economy.js    склад, цены, торговля, дефицит
    events.js     погода, стройка-планировщик, рождения/смерти
    simulation.js оркестратор
  render/  — визуализация (не меняет состояние мира)
    iso.js        изометрическая проекция
    terrain.js    запечённая местность (диорама)
    buildings.js  здания и малые формы
    entities.js   деревья и фигурки жителей
    fx.js         частицы
    renderer.js   слои, камера, свет день/ночь, погода
  ui/ui.js — панели, хроника, топбар, модалки
  main.js  — игровой цикл
```

Симуляция детерминирована зерном (seed) — один и тот же seed даёт одинаковый
мир при одинаковых действиях наблюдателя.
